# Setup.md — Internshala Clone: Initial Setup Commands

## Prerequisites

Install these tools before running any setup commands:

| Tool | Version | Download |
|---|---|---|
| Node.js | 20.x LTS | https://nodejs.org |
| .NET SDK | 9.0 | https://dotnet.microsoft.com/download |
| SQL Server | 2022 | https://www.microsoft.com/sql-server |
| SQL Server Management Studio | 20.x | Via Microsoft Store or installer |
| Docker Desktop | Latest | https://www.docker.com/products/docker-desktop |
| Git | 2.43+ | https://git-scm.com |
| Visual Studio Code | Latest | https://code.visualstudio.com |
| Azure CLI | Latest | https://docs.microsoft.com/cli/azure/install-azure-cli |

## Step 7: SQL Server Setup

```sql
-- Connect to SQL Server via SSMS or sqlcmd and run:

-- Create database
CREATE DATABASE InternshalaDb
    COLLATE SQL_Latin1_General_CP1_CI_AS;
GO

-- Set compatibility level to SQL Server 2022
ALTER DATABASE InternshalaDb SET COMPATIBILITY_LEVEL = 160;
GO

-- Enable Read Committed Snapshot Isolation (prevents reader-writer blocking)
ALTER DATABASE InternshalaDb SET READ_COMMITTED_SNAPSHOT ON;
GO

-- Enable snapshot isolation
ALTER DATABASE InternshalaDb SET ALLOW_SNAPSHOT_ISOLATION ON;
GO

-- Create application login and user
USE InternshalaDb;
GO

CREATE LOGIN internshala_app WITH PASSWORD = 'YourSecureDevPassword123!';
CREATE USER internshala_app FOR LOGIN internshala_app;
ALTER ROLE db_datareader ADD MEMBER internshala_app;
ALTER ROLE db_datawriter ADD MEMBER internshala_app;
GRANT EXECUTE TO internshala_app;
GO

-- Create audit schema
CREATE SCHEMA audit AUTHORIZATION dbo;
GO

-- Create config schema
CREATE SCHEMA config AUTHORIZATION dbo;
GO

-- Enable Full-Text Search (required for internship search)
USE InternshalaDb;
GO
CREATE FULLTEXT CATALOG ft_catalog AS DEFAULT;
GO
```

## Step 8: Configure User Secrets (.NET)

```powershell
cd backend/Internshala.API

# Initialize user secrets
dotnet user-secrets init

# Database
dotnet user-secrets set "ConnectionStrings:DefaultConnection" `
  "Server=.;Database=InternshalaDb;User Id=internshala_app;Password=YourSecureDevPassword123!;TrustServerCertificate=True"

# Generate RSA key pair for JWT (RS256)
# Option 1: Use OpenSSL
openssl genrsa -out jwt-private.pem 2048
openssl rsa -in jwt-private.pem -pubout -out jwt-public.pem
# Convert to base64 for storage
$privateKey = [Convert]::ToBase64String([IO.File]::ReadAllBytes("jwt-private.pem"))
$publicKey = [Convert]::ToBase64String([IO.File]::ReadAllBytes("jwt-public.pem"))

dotnet user-secrets set "Jwt:PrivateKeyBase64" $privateKey
dotnet user-secrets set "Jwt:PublicKeyBase64" $publicKey
dotnet user-secrets set "Jwt:Issuer" "internshala-api"
dotnet user-secrets set "Jwt:Audience" "internshala-web"
dotnet user-secrets set "Jwt:AccessTokenExpiryMinutes" "15"
dotnet user-secrets set "Jwt:RefreshTokenExpiryDays" "7"

# Email (Mailhog for dev)
dotnet user-secrets set "Email:Provider" "Smtp"
dotnet user-secrets set "Email:SmtpHost" "localhost"
dotnet user-secrets set "Email:SmtpPort" "1025"
dotnet user-secrets set "Email:FromAddress" "noreply@internshala-dev.com"
dotnet user-secrets set "Email:FromName" "Internshala (Dev)"

# Redis
dotnet user-secrets set "Redis:ConnectionString" "localhost:6379"

# File Storage (Azure Blob dev emulator or Azurite)
dotnet user-secrets set "Storage:ConnectionString" "UseDevelopmentStorage=true"
dotnet user-secrets set "Storage:ContainerName" "internshala-dev"

# Clean up key files
Remove-Item jwt-private.pem, jwt-public.pem
```

## Quick Start (After Initial Setup)

Once the full setup is done, use this quick start for daily development:

```powershell
# 1. Start infrastructure
docker-compose up -d sqlserver redis mailhog seq

# 2. Start API (in one terminal)
cd backend && dotnet run --project Internshala.API

# 3. Start Angular (in another terminal)
cd frontend && ng serve

# 4. Open URLs
Start-Process "http://localhost:4200"       # Angular app
Start-Process "http://localhost:5000/swagger" # API docs
Start-Process "http://localhost:8025"         # Mailhog (emails)
Start-Process "http://localhost:5342"         # Seq (logs)
```

## Troubleshooting

### Common Issues

| Issue | Solution |
|---|---|
| `ng` command not found | Run `npm install -g @angular/cli` again |
| `dotnet ef` command not found | Run `dotnet tool install --global dotnet-ef` |
| SQL Server connection refused | Verify Docker container is running: `docker-compose ps` |
| Angular Material styles missing | Run `ng add @angular/material` again |
| JWT key errors | Re-generate RSA keys and update user-secrets |
| EF migration fails | Check connection string in user-secrets |
| Port 4200 in use | Change port: `ng serve --port 4201` |
| Port 5000 in use | Set `ASPNETCORE_URLS=http://+:5001` |
| `npm install` errors | Delete `node_modules` and `package-lock.json`, re-run `npm install` |
| Husky hooks not running | Run `npx husky install` in root directory |

### Reset Everything (Nuclear Option)

```powershell
# Stop and remove all Docker containers and volumes
docker-compose down -v

# Reset Angular
cd frontend && Remove-Item -Recurse -Force node_modules, dist, .angular
npm install

# Reset .NET
cd ..\backend && dotnet clean && dotnet restore

# Reset database (will lose all data!)
docker-compose up -d sqlserver
# Wait 30 seconds for SQL Server to start
Start-Sleep 30
dotnet ef database update --project Internshala.Infrastructure --startup-project Internshala.API

Write-Host "Reset complete!" -ForegroundColor Green
```
